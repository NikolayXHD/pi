# Локальная сборка

Заметки про пересборку и обновление глобального `pi` из этого
репозитория. Стандартная сборка работает как в upstream — см.
`README.md` → Development; здесь только пошаговая инструкция для этой
машины.

## Первичная установка (свежий клон)

1. Поставить зависимости с нуля:

   ```bash
   npm ci --ignore-scripts
   ```

   Готовый `node_modules` не переиспользовать и не освежать: его
   происхождение неизвестно, а `npm install` принимает его молча, ничего
   не пересобирая.

2. Собрать и обновить каталог моделей:

   ```bash
   npm run build
   ```

   Шаг обновления каталога (`npm run hydrate:model-data`) тянет данные
   с `models.dev`, который с этой сети доступен. Если сети нет — см.
   «Офлайн-каталог моделей» ниже.

3. Проверить:

   ```bash
   npm run check
   ```

4. Поставить глобальный `pi` из собранного пакета:

   ```bash
   npm install -g ./packages/coding-agent --ignore-scripts
   ```

   Создаётся симлинк из глобального `node_modules` на
   `packages/coding-agent`. `npm run clean` или удаление репозитория
   ломают глобальный `pi`.

5. Проверить установку:

   ```bash
   pi --version
   pi -p "Say exactly: ok"
   ```

## Обновление

1. Актуализировать репозиторий (`git pull`).
2. Пересобрать (`npm run build` и `npm run check`).
3. Повторно выполнить глобальную установку из п. 4 (если ничего не
   изменилось — она ничего не делает).
4. Запущенная сессия `pi` продолжает выполнять старый код, пока её не
   перезапустить.

## Офлайн-каталог моделей

Каталог `packages/ai/src/providers/data/` в git не хранится; в свежем
клоне его нет. Онлайн он восстанавливается сам (см. п. 2). Офлайн —
скопировать каталог целиком с машины, где он есть, включая служебный
файл `.manifest.json`: без него падает `check:model-data` (глоб
`*.json` его не захватывает).

Пакет из upstream (`npm pack @earendil-works/pi-ai`) источником не
служит: в нём полный upstream-каталог (40+ провайдеров), а в этом
дистрибутиве их 16, и `check:model-data` падает на расхождении.

## Диагностика

Если `tsgo` падает с `error TS2353` про значение `api` у модели в
`packages/ai/src/providers/*.ts`, а `check:model-data` при этом
проходит — данные и код разошлись (устаревший hydrate перенёс модели
провайдера на другой API). Перезапустить hydrate или освежить
`.models.ts` соответствующего провайдера.
